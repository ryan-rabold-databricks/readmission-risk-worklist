- Whether app stdout/stderr is exported to `app_otel_logs` without instrumentation (not stated in the docs); the build emits audit events explicitly either way.
- The OpenTelemetry logs exporter setup for Node/AppKit (the docs show traces and metrics only). Partly answered: AppKit 0.76.1 registers a global OTLP LoggerProvider when `OTEL_EXPORTER_OTLP_ENDPOINT` is set (`telemetry-manager.js`); verify after deploy that records reach `app_otel_logs`.
- Delivery semantics for app telemetry through Zerobus; de-duplicate on `event_id` regardless.
- Whether SDP pipelines can declare FOREIGN KEY constraints to tables in the same pipeline (failed in update b789d7); revisit or add FKs after the pipeline with a setup step.
